# RimManager v0.1.0

首个 Windows x64 版本。解压发布包并运行 `RimManager.exe`。

## 模组管理

- 自动发现 Steam 游戏库，读取 RimWorld 已启用顺序、本地模组与工坊模组。支持手动设置路径。
- 桌面三栏展示未启用模组、已启用模组和介绍。可查看类型、依赖关系并打开创意工坊。
- 已启用列表直接绘制依赖连线，显示缺失前置和顺序异常。两个列表均标记游戏版本不兼容。
- 支持拖动排序、自动排序预览、导入和导出 JSON 清单。导入遇到缺失项时可跳过或取消。

## 更新与启动

- 查询创意工坊新版，支持更新所选和全部更新。锁定版本的条目保持可见，批量更新会跳过它们。
- 支持通过 Steam 启动游戏并传入自定义参数。应用清单时备份现有游戏配置，支持从备份恢复顺序。
- 工坊下载需要单独安装 SteamCMD。首版使用匿名下载，受 Steam 访问权限限制。版本锁约束 RimManager 发起的更新，Steam 客户端自行同步的工坊内容由 Steam 管理。
